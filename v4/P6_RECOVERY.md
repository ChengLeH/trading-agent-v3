# P6 結構與中斷恢復修正驗收（2026-10-17）

> 本文記錄 2026-10-17 的初版修復。續接預設、自動續接及可調預算已在 2026-10-18 更新，請以 [P6 最新修復驗收](P6_BUGFIX_ACCEPTANCE.md) 為準。

## Problem（問題）

P6 每個子節點重帶整串祖先及其來源，使深鏈反覆審相同內容；逾時後臨時工作目錄及對話身分消失，重試從新對話開始；重新載入檢查點又產生新驗證執行識別碼，使已完成項目必須重新呼叫模型。這是共用流程問題，本次沒有針對單一 ticker、VM 或特定 87 條報告加例外。

## Root Cause（完整因果鏈）

以修正前 `489946e` 為基準：

1. `atomic_phase6.py::build_atomic_tasks` 遞迴收集所有祖先 → `build_atomic_prompt` 直接序列化完整任務 → 深度越大，重複送出的祖先及來源越多。深度覆核及修補也使用完整任務；全局掃描重帶正式物件、同內容 Markdown 與整份歷史。
2. `agy_session.py::run_session` 使用暫存目錄，逾時結束子程序 → 沒有持久對話身分可接續 → `cloud.py::complete` 對可重試失敗重新開始請求。
3. `checkpoint.py::load_checkpoint` 清空收據且建立新執行識別碼 → `journal.py::complete` 只重播角色產生結果，不重播驗證結果 → 檢查點有正式物件，卻仍重做全部付費驗證。

修正後位置：`atomic_phase6.py::AtomicTask.review_dict`、`agy_session.py::run_session`、`session_state.py::SessionState`、`checkpoint.py::load_checkpoint`、`journal.py::RunJournal.complete`、`runner.py::prepare_phase6_global_sweep`。

## Fix（修正與影響範圍）

- 新增持久對話狀態、原始請求、串流事件及跨程序鎖；保留相同代理設定、隔離目錄與對話 ID。
- 已送出且確認接收後的逾時／空回覆改為待續狀態，普通重試不另開對話。明確續跑只傳接續訊息，最多兩次，時間預算跨程序保存；硬中止保守扣除預留額度。
- 未確認送達時封鎖，不盲目重送；舊子程序仍在或事件檔損壞也封鎖。已完整保存的成功結果可零模型呼叫恢復，再通過 JSON 與語義回覆契約驗收。
- 原子、深度及修補任務只傳當前 Claim（論述）、直接前提及明確相關來源。Calc／Event 的來源連結仍遞迴保留。正式雜湊仍包含全部祖先與來源，因此上游修改仍使下游失效。
- 全局掃描保留全體 Claim、依賴關係、交易物件及修改前後完整 Claim；移除重複 Markdown、冗餘歷史及已在原子／深度層審過的 Evidence 摘錄。
- 檢查點預設延續同一驗證執行。只重播 run、epoch、完整提示、正式任務、規格、模型及代理設定一致的已保存回覆，並重新通過 collector（結果驗收器）；不直接恢復檢查點的稽核收據。
- 增加明確的新一輪選項 `--fresh-verification`。缺執行識別碼的舊檢查點要求明確選擇，不默默花費重驗。
- 超出逐條輸入預算時在呼叫前封鎖，保留原資料，要求結構化來源範圍或明確調整預算；不截斷證據、不用文字規則猜重要性。

執行程式碼變更限 `v4/`，另在 `.gitignore` 排除含研究資料的預設對話目錄；未改 V3、`main`、全域設定或工具權限，未增加 API 轉接或本地模型。

## 未解事項、更新與回滾

- 同一對話續接能恢復上下文，不能保證逐輸出片段游標續算或供應商保留未完成推理。此次實測不是 20 分鐘真實分析的中途運算恢復測試。
- 舊 run 未保存對話 ID 時，不能事後憑空恢復。外部 driver（驅動程式）仍須遵守 `retryable=false`，或採用 V4 自動入口／RunJournal；自行包多層盲目重試不在函式庫控制範圍。
- 主程序硬中止後舊子程序可能繼續存在；本版會拒絕第二個付費回合，沒有背景監管服務。PID 重用可能保守封鎖，程式不擅自殺程序或丟棄對話。
- 續跑到另一個輸出目錄時，要保留原本的 sessions 目錄；完整對話與部分輸出仍位於該目錄。
- 模型本身的分析速度及完整報告的總耗時／費用尚未驗收，不宣稱問題在所有真實資料上已消失。
- 使用新版須重新啟動 V4 驅動程序；執行中的舊程序不會自動更新。V3 不需重啟。回滾至 `489946e` 或撤回本輪提交即可；保留整個輸出目錄，不刪檢查點與 sessions。新版同執行續跑能力在舊版不適用。
